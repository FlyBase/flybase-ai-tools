# FlyBase MCP tool catalog

Generated by `cargo run --bin tool-catalog`. Do not edit by hand.

## `batch_download`

Download chosen fields for up to 500 FlyBase IDs at once as rows (JSON or TSV): symbols, names, locations, synonyms, references, GO terms, alleles, transcripts, human orthologs, allele classes, stocks, and more. Use list_options=true to see the field catalog. Use when you have a list of IDs and want a table; use get_report for one entity in depth.

```json
{
  "$defs": {
    "Format": {
      "enum": [
        "json",
        "tsv"
      ],
      "type": "string"
    }
  },
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "additionalProperties": false,
  "properties": {
    "fields": {
      "description": "Field names from the catalog; pass list_options=true to see them by class.",
      "items": {
        "type": "string"
      },
      "type": "array"
    },
    "format": {
      "anyOf": [
        {
          "$ref": "#/$defs/Format"
        },
        {
          "type": "null"
        }
      ],
      "description": "json (default) returns rows as objects; tsv returns a tab-separated text block and row_count instead."
    },
    "ids": {
      "description": "Up to 500 FlyBase IDs (secondary IDs are updated first).",
      "items": {
        "type": "string"
      },
      "type": "array"
    },
    "list_options": {
      "description": "If true, return only the field catalog.",
      "type": [
        "boolean",
        "null"
      ]
    }
  },
  "required": [
    "ids",
    "fields"
  ],
  "type": "object"
}
```

## `get_interactions`

A self-interaction lists the gene as its own partner; allele comparisons give genotype (whose phenotype is described), compared_with, and side (which of the two carries the allele). One hop only; call again on a partner to go further. Use get_report sections for everything else about the gene.

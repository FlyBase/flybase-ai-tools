# FlyBase MCP tool catalog

Generated by `cargo run --bin tool-catalog`. Do not edit by hand.

## `get_report`

Return the data shown on a FlyBase report page for a gene (FBgn), allele (FBal), reference (FBrf), or stock (FBst) ID; more report types arrive in later releases. Choose sections to keep responses small; use list_options=true to see section names. Use resolve first if you only have a symbol.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "additionalProperties": false,
  "properties": {
    "id": {
      "description": "A gene, allele, reference, or stock ID (FBgn, FBal, FBrf, FBst). Secondary and obsolete IDs are resolved first.",
      "type": "string"
    },
    "limit_per_section": {
      "description": "Max items per list section (default 25, max 100).",
      "format": "uint32",
      "minimum": 0,
      "type": [
        "integer",
        "null"
      ]
    },
    "list_options": {
      "description": "If true, return only the section names available for this ID's type.",
      "type": [
        "boolean",
        "null"
      ]
    },
    "sections": {
      "description": "Sections to return. Omit for the type's default summary set. Pass list_options=true to see valid names.",
      "items": {
        "type": "string"
      },
      "type": [
        "array",
        "null"
      ]
    }
  },
  "required": [
    "id"
  ],
  "type": "object"
}
```

## `list_species`

## `resolve`

Turn one gene, allele, insertion, stock, cell line, library, strain, or other symbol, name, synonym, stock number, or ID into current FlyBase IDs. Handles obsolete and secondary IDs. Use this first whenever you have a name and need an ID for another tool. For a batch of exact IDs use validate_ids; for free-text discovery use search.

```json
{
  "$defs": {
    "DataClass": {
      "enum": [
        "gene",
        "allele",
        "insertion",
        "construct",
        "aberration",
        "balancer",
        "gene_group",
        "disease_model",
        "stock",
        "ortholog",
        "split_system_combination",
        "cell_line",
        "library",
        "strain"
      ],
      "type": "string"
    }
  },
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "additionalProperties": false,
  "properties": {
    "data_class": {
      "anyOf": [
        {
          "$ref": "#/$defs/DataClass"
        },
        {
          "type": "null"
        }
      ],
      "description": "Restrict to one data class."
    },
    "limit": {
      "description": "Max matches to return (default 25, max 100).",
      "format": "uint32",
      "minimum": 0,
      "type": [
        "integer",
        "null"
      ]
    },
    "query": {
      "description": "A symbol (N, w[1118]), full name (Notch), synonym, or any FlyBase ID (FBgn0004647, including obsolete or secondary IDs).",
      "type": "string"
    },
    "species": {
      "description": "FlyBase species abbreviation such as Dmel or Hsap. Default: any species.",
      "type": [
        "string",
        "null"
      ]
    }

  "required": [
```

## `search`

Returns a paged hit list. Use resolve when you already know the exact symbol or ID.

# Bundled coordinate maps

`dmel_r5_to_r6.tsv`: D. melanogaster assembly release 5 to release 6, 6,621 blocks, generated by
`scripts/build_coordinate_map.sh` from FlyBase's published map `Schroeder.Dmel_r5-to-r6_map.2014.6.12.txt.gz`
(FTP `flybase/associated_files/`), cross-checked against the copy in FlyBase's `bulkfile-scripts` converter.
Licence: `LICENSE.bulkfile-scripts` (BSD-3-Clause, FlyBase and Indiana University, 2014, the `LICENSE` of `FlyBase/bulkfile-scripts` at commit 10ed49d).
Columns are tab separated: `from_chr from_start from_end to_chr to_start to_end strand`, 1-based inclusive on
both releases. A `-` strand block is reverse complemented in release 6.

The FlyBase website converter also offers Dmel releases 3 and 4 and D. pseudoobscura release 2, but FlyBase
publishes no map files for those pairs, so they are not supported here. Re-run the script if FlyBase republishes
the map; `cargo test --lib` checks the known conversions.
